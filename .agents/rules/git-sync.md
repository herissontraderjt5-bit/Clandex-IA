# Regra de Sincronização com o GitHub

Sempre que realizar qualquer alteração, correção ou nova funcionalidade no projeto:
1. Validar e compilar as alterações.
2. Adicionar os arquivos modificados ao Git (`git add`).
3. Criar um commit descritivo no padrão Conventional Commits (`git commit -m "..."`).
4. Fazer o push das alterações imediatamente para o repositório remoto no GitHub (`git push origin main`).
